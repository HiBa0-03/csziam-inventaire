# CSZIAM Inventaire

Application web de gestion du patrimoine et des inventaires du Centre CSZIAM.

L’application permet de centraliser la gestion des articles, utilisateurs, services, laboratoires, mouvements et campagnes d’inventaire, avec une interface web et des fonctionnalités d’export et de génération de rapports.

## Technologies utilisées

### Backend

* Java 21
* Spring Boot
* Spring Data JPA / Hibernate
* MySQL
* Maven
* Lombok
* Validation
* REST API
* Spring Security
* JWT

### Frontend

* Next.js
* React
* TypeScript
* HTML / CSS

### Outils

* Git / GitHub
* IntelliJ IDEA
* Visual Studio Code

## Fonctionnalités

* Gestion des utilisateurs
* Gestion des catégories
* Gestion des laboratoires
* Gestion des services organisationnels
* Gestion des articles
* Gestion des mouvements
* Gestion des campagnes d’inventaire
* Authentification et gestion des rôles
* Tableau de bord avec statistiques
* Génération de rapports basée sur l’intelligence artificielle
* Export des rapports en PDF
* Export des données d’inventaire en Excel
* Interface web pour la gestion et le suivi des inventaires

## Architecture du projet

Le projet est organisé en deux parties :

```text
csziam-inventaire/
│
├── src/                              # Backend Spring Boot
├── pom.xml
│
└── gestioninventaire-frontend/      # Frontend Next.js
    ├── src/
    ├── public/
    ├── package.json
    └── ...
```
