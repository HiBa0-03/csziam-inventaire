# CSZIAM Inventaire

Application web de gestion du patrimoine du Centre CSZIAM.

## Technologies utilisées

- Java 
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- Lombok
- Validation
- REST API

## Fonctionnalités

- Gestion des utilisateurs
- Gestion des catégories
- Gestion des laboratoires
- Gestion des services organisationnels
- Gestion des articles
- Gestion des mouvements
- Authentification par rôles (en cours)
